          Where to get other countries

          On Wi‑Fi, open download.geofabrik.de, choose a country and download the file ending in .osm.pbf. Then tap “Add a country map file” and choose it. Map data © OpenStreetMap contributors. World map: Natural Earth.

          Get maps and models

            A download that stops carries on from where it stopped; keep the app open while it runs. Each file is checked before it is used. The same files are on the downloads page. A file from there, a memory card, a USB stick or another phone goes in with “Import a file”.

            Share with no data

            Send the app, this map or the AI model to a phone nearby. In the list that opens, choose Quick Share (Nearby Share) or Bluetooth. No data or airtime is used.

            Or send straight to a phone linked in Chat. Both phones: Chat → Find nearby phones.
